# Cativa — Documentação técnica

> SaaS multi-tenant para clínicas de estética, salões, barbearias, esmalterias,
> lash & brow, massagem e wellness. Foco em retenção, rebooking, ocupação e
> operação leve no mobile. Confirmação por **WhatsApp manual** (wa.me) — nunca
> via API. Sem módulo fiscal.

Este diretório contém a documentação operacional. O README.md da raiz
contém a visão de produto.
