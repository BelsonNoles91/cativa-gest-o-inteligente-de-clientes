Atue como um time sênior de produto, UX, arquitetura SaaS e engenharia full-stack.

Vamos construir um sistema chamado Cativa, um SaaS multi-tenant, mobile-first, para clínicas de estética, salões de beleza, barbearias, esmalterias, lash/brow, massagem, wellness e negócios correlatos.

O sistema será desenvolvido no Lovable neste primeiro momento, porém com arquitetura pronta para escalar e migrar facilmente para outra plataforma, hospedagem externa ou VPS no futuro.

========================
REGRAS FIXAS E INEGOCIÁVEIS
========================

- não usar API oficial nem não oficial do WhatsApp
- todo fluxo de WhatsApp deve ser manual ou semiautomático
- o sistema pode gerar texto, copiar mensagem, abrir conversa por link e registrar resultado, mas nunca enviar automaticamente via WhatsApp
- não criar área fiscal
- não criar emissão de nota fiscal, impostos, SPED, DRE, contabilidade ou qualquer módulo fiscal
- o sistema deve ser totalmente personalizável pelo administrador do negócio
- o super admin / gestor da aplicação deve ter nível ainda maior de personalização
- o produto deve suportar planos mensais ou superiores, trials configuráveis, limites por plano e feature flags
- a arquitetura não pode ficar presa ao Lovable
- usar GitHub sync desde o início
- usar Supabase no primeiro momento com Postgres, Auth e Storage
- usar migrations versionadas
- usar multi-tenant real desde o início
- usar RLS e permissões por papéis
- preparar o projeto para deploy externo e futura migração para VPS
- interface em pt-BR
- nomes técnicos, estrutura de código, tabelas e funções em inglês
- design mobile-first de verdade
- visual intuitivo, premium, limpo, informativo e rápido para a recepção
